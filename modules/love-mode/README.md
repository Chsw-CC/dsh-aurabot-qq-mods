# 快来跟我恋爱吧（love-mode）

教你的 AI 伙伴怎么爱你：选择一种关系模式，她的相处风格、主动程度、聊天技巧会整体切换。这不是给你出主意的军师——是她自己学会怎么和你相处。

## 功能

- 六种关系模式：单身约会 / 长期伴侣 / 婚姻 / 异地 / 再婚 / 跨文化关系
- 双方画像：她和你的 MBTI、优势、短板，由 AI 根据人格卡和记忆自动生成，可微调
- 自动匹配：首次启动自动分析你们的聊天记录选模式；面板按钮随时重跑
- 简单/高级面板：简单页只选模式；高级页微调滑块、基调文案、画像
- 与主动搭话联动：「主动程度」滑块影响她主动找你的频率（若装了关系阶段模块）

## 配置

面板「扩展」→「快来跟我恋爱吧」：

1. 点「自动匹配」让她自己判断你们处在哪个模式（或手动选）
2. 高级里可微调：幽默/主动/走心滑块、基调文案、双方画像、你的性别与关系性质声明
3. 勾选「锁定我的微调」后，自动匹配不再覆盖你改过的滑块和基调

## 会访问哪里

- 读取：人格卡 `personas/dafeiyu.md`（前 2000 字，用于自动匹配）、记忆库（只读召回）
- 写入：本模块设置（`config.json` 的 `ext.love-mode`）、`modules-data/love-mode/state.json`
- 不联网（自动匹配走插件自身的模型通道）、不向主人以外的任何人发消息
