# 薅羊毛任务中心

Aurabot 用户扩展模块，参考青龙面板的订阅、环境变量、定时任务和日志模型。

## 内置订阅

- https://github.com/cyuni1996/jdpro
- https://github.com/hex-ci/smzdm_script
- https://github.com/smallfawn/QLScriptPublic

可以添加、编辑、切换 Git 源和分支、同步、删除订阅，并浏览其中的脚本。

## 使用

1. 在「订阅源」中同步仓库。同步只下载源码，不执行脚本、不执行 `sub_after`、不自动安装依赖。
2. 在「定时任务」中选择订阅、读取脚本并添加任务。任务默认停用，可修改 Cron 后逐条启用。
3. 在「环境变量」中手动添加变量，或使用京东 App 扫码生成 `JD_COOKIE`。变量值不在面板和日志中回显。
4. 先手动运行并检查日志，再启用定时。

支持 JS/MJS/CJS、Python、Shell；支持 5 字段和 6 字段 Cron。任务超时、停止、退出码和最近 200 条运行元数据会保存，面板展示最近 100 条。

## 运行环境

- Git 必须可用，用于订阅同步。
- Node.js 默认使用 DSH 当前进程，并设置 `ELECTRON_RUN_AS_NODE=1` 兼容桌面 Electron。
- Python 和 Bash 默认从 PATH 查找，也可在模块设置里指定绝对路径。
- 第三方仓库的依赖需要在对应 `modules-data/wool-runner/repos/<订阅>` 目录中按上游说明安装。模块不会自动执行依赖安装脚本。

## 联网目标

- `github.com`：用户主动同步时，通过 Git 下载所选订阅源码。
- `qr.m.jd.com`：京东官方二维码生成与扫码状态查询。
- `passport.jd.com`：京东官方扫码票据校验；仅允许继续访问 `*.jd.com` 的官方 HTTPS 跳转。
- 用户手动运行或启用定时后，第三方脚本可能访问其各自服务；这些域名以脚本源码为准，需在添加任务前审查。

扫码凭据只写入本机环境变量，不会发送到上述官方登录域名之外的服务。

## 安全说明

- 第三方脚本拥有其运行账号的权限，可能造成账号限制、内容发布或其他副作用。使用前请审查源码、活动状态、许可证与平台规则。
- 所有脚本任务默认停用，只有手动运行或明确启用定时后才执行。
- 扫码直接访问京东 Passport 官方接口，不经过第三方登录服务。Cookie 只保存在 Aurabot 本机数据目录，文件权限尽可能限制为当前用户。
- 日志写入和读取会隐藏已保存的环境变量值及常见 Cookie/Token 字段。
- 删除订阅默认保留源码；删除任务不删除源码。

## QQ 命令

- `/羊毛 列表`
- `/羊毛 运行 完整任务名`

模块也提供仅主人私聊可用的 `wool_tasks` 工具，只能列出或运行已有任务，不能读取环境变量或修改配置。
